# Agent Spells

Agent Spells is an experimental protocol layer pairing a small runtime kernel with automated validation of skill and MCP execution.

There are two separate deliverables:

- **FORMAT** — the portable `SPELL.md` declaration standard in `format/`.
- **KERNEL** — runtime validation, observation, authority resolution, execution classification, and CAST records in `kernel/`.

`Familiar` is a caster-owned dialect and judgment artifact. It is not the umbrella name for the system and is not required for casting.

`Spellcraft` and `Find Familiar` are ordinary Agent Skills used to author/repair `SPELL.md` and Familiar artifacts respectively.

See [AGENT_SPELLS.md](AGENT_SPELLS.md) for the structural validation and 0.2 baseline.
